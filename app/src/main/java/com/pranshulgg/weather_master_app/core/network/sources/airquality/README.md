# Air Quality

This folder is for airquality-specific API implementations

### Rules

- Only add APIs here when the source provides **Air Quality only**.
- If air quality comes from a source that also provides weather, keep the API under that source's
  existing
  folder instead. You can take a look at **AccuWeather** implementation
- A single source should have a single source-level implementation/folder, even if it exposes
  multiple endpoints.
